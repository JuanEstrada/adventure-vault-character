# Documentation Guidelines

## Estilo

- Markdown simple y legible.
- Titulos descriptivos.
- Secciones cortas y orientadas a decisiones o contexto.
- Diagramas Mermaid solo cuando aporten claridad.

## Mantenimiento

- Actualizar documentacion junto con cambios de codigo o alcance.
- Evitar copiar el mismo contenido en varias secciones.
- Mover decisiones a ADR cuando tengan impacto arquitectonico.

## Trazabilidad

- Producto en `docs/product/`
- Arquitectura en `docs/architecture/`
- Proceso documental en `docs/workflows/`
