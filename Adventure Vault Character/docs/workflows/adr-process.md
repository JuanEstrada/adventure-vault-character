# ADR Process

## Cuando crear un ADR

- Al elegir una estructura arquitectonica.
- Al decidir integraciones relevantes.
- Al fijar patrones de persistencia, sincronizacion o seguridad.
- Al aceptar restricciones importantes.

## Plantilla minima

- Estado
- Fecha
- Contexto
- Decision
- Consecuencias

## Regla de oro

Si una decision cuesta explicar en una conversacion, probablemente merece un ADR.
