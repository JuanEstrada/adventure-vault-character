# 12. Glossary

## Terminos

- `Adventure Vault Character`: aplicacion orientada a jugadores para gestionar personajes.
- `Personaje`: entidad jugable con atributos, progreso y recursos.
- `Sesion del master`: contexto activo de partida al que se conecta el jugador.
- `Contenido base`: informacion oficial o gratuita disponible para consulta.
- `Contenido importado`: informacion agregada por el usuario mediante XML.
- `Guia asistida`: flujo paso a paso para crear o evolucionar un personaje.
- `Sistema de juego`: conjunto de reglas como DND u otros juegos de rol compatibles en el futuro.
