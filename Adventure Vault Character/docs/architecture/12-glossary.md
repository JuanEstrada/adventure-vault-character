# 12. Glossary

- **Adventure Vault**: the overall product family that includes player and DM
  applications.
- **Adventure Vault Character**: the player-facing Flutter application
  documented in this repository.
- **Adventure Vault Master**: the future Dungeon Master application.
- **Drift**: the Dart persistence layer used as an abstraction over SQLite.
- **Flutter**: the client application framework used for the player app.
- **Local-first**: an architectural approach in which the device-local state is
  the primary source for application behavior.
- **D20 mechanics**: rules involving twenty-sided dice rolls, modifiers, and
  related outcome calculations.
- **XML import**: the process of loading rules-related content into the
  application from XML files.
