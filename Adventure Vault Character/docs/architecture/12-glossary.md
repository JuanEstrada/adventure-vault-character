# 12. Glossary

- **Adventure Vault**: the overall product family that includes player and DM applications.
- **Adventure Vault Character**: the player-facing Android application documented in this repository.
- **Adventure Vault Master**: the future Dungeon Master application.
- **Local-first**: an architectural approach in which the device-local state is the primary source for application behavior.
- **D20 mechanics**: rules involving twenty-sided dice rolls, modifiers, and related outcome calculations.
- **XML import**: the process of loading rules-related content into the application from XML files.
- **Room**: the Android persistence library used as an abstraction over SQLite.
