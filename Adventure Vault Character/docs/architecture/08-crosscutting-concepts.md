# 08. Crosscutting Concepts

## Conceptos transversales iniciales

### Dominio

El personaje es la entidad central. Inventario, spells, experiencia, nivel, contenido disponible y sesion activa deben tratarse como capacidades conectadas pero diferenciadas.

### Seguridad

La autenticacion y autorizacion deben impedir acceso indebido a personajes y sesiones.

### Importacion de contenido

El contenido XML necesita validacion, trazabilidad de origen y una frontera clara entre contenido base y contenido agregado por usuario.

### Evolucion a multiples sistemas

Las reglas del juego no deben quedar acopladas de forma irreversible a DND si se espera soportar otros sistemas despues.

### Documentacion

Toda decision importante debe reflejarse en ADR o en secciones arquitectonicas relacionadas.
