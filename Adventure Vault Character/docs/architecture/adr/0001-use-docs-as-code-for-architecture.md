# 0001 Use Docs As Code For Architecture

- Estado: Aceptado
- Fecha: 2026-03-12

## Contexto

Adventure Vault esta en una etapa temprana y necesita una base documental facil de evolucionar junto con el repositorio.

## Decision

La documentacion de arquitectura se mantendra como Markdown dentro del repo bajo `docs/`.

## Consecuencias

- Las decisiones y cambios quedan versionados junto con el proyecto.
- La barrera para contribuir es baja.
- Se requiere disciplina para mantener la documentacion actualizada.
