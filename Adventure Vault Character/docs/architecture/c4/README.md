# C4 Model

Las vistas C4 describen Adventure Vault con distintos niveles de detalle.

## Vistas incluidas

- `system-context.md`: actores y sistemas externos.
- `container-view.md`: contenedores o unidades desplegables/logicas principales.
- `component-view-app.md`: componentes relevantes del cliente de jugador.
- `component-view-backend.md`: componentes relevantes del backend o nucleo de negocio.

## Nota

Estas vistas son iniciales y deben ajustarse cuando el diseño tecnico se concrete.
