# Arquitectura

Esta seccion documenta la arquitectura de Adventure Vault con un enfoque combinado:

- `arc42` para organizar la narrativa arquitectonica.
- `C4` para representar el sistema desde contexto hasta componentes.
- `ADR` para registrar decisiones de arquitectura.

## Estado actual

La arquitectura documentada aqui representa una base inicial. El proyecto aun esta en etapa temprana y varias secciones describen arquitectura objetivo, no arquitectura implementada.

## Alcance arquitectonico

La documentacion cubre la solucion de `Adventure Vault Character`, la app orientada a jugadores. La futura app del master se trata como sistema externo relacionado, no como parte del alcance actual de implementacion.

## Navegacion

- Secciones `01` a `12`: estructura base de `arc42`.
- `c4/`: vistas visuales y narrativas del sistema alineadas con los bloques descritos en `05-building-block-view.md`.
- `adr/`: decisiones arquitectonicas versionadas y referenciadas desde `09-architecture-decisions.md`.
