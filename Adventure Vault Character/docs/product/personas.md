# Personas

## Jugador

- Quiere crear y mantener uno o varios personajes sin perder informacion.
- Necesita acceso rapido a reglas, habilidades, items y spells.
- Espera una experiencia clara para crear personaje, jugar y subir de nivel.

## Equipo de producto y desarrollo

- Necesita una base de dominio y arquitectura entendible.
- Requiere decisiones explicitadas para poder iterar sin duplicidades.
