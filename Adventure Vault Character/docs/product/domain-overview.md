# Domain Overview

## Entidades de dominio iniciales

- `Personaje`
- `Clase`
- `Raza`
- `Spell`
- `Item`
- `Monstruo`
- `Sesion`
- `Experiencia`
- `Nivel`
- `Contenido importado`

## Relaciones clave

- Un jugador administra uno o varios personajes.
- Un personaje usa contenido de reglas y puede cambiar durante una sesion.
- El contenido puede venir de una fuente base o de XML importado.
